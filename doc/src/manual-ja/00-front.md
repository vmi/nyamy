# NYamy - マニュアル

NYamy (*N*ew *Yamy*) は、「窓使いの憂鬱」およびその派生ソフトウェア「YAMY」/「Yamy私家版 (ymgw版)」からさらに派生した、64bit Windows 専用の汎用キーバインディング変更ソフトウェアです。(32bitアプリ用のフックDLLが含まれておりますので、64bit Windows 上で動作する32bitアプリには対応しています)

本ソフトウェアは YAMY のソースコードを全面的にリフレッシュした上で、マクロ言語として mruby を組み込んだことにより、少なからず YAMY との互換性が失われたことから、新たな YAMY ということで NYamy と改名しました。
