## 3. menu {#MENU}

NYamy を実行すると、タスクトレイに NYamy のアイコンが表示されます。この NYamy のアイコンを右クリックするとメニューが出てきます。

![](menu-ja.png)

<span class="menu-item"><a name="menu-r"></a>再読み込み(<u>R</u>)</span>

:   設定ファイルを再読み込みします。[`&LoadSetting`](#function_LoadSetting) と同じです。

<span class="menu-item"><a name="menu-c"></a>選択(<u>C</u>) ►</span>

:   サブメニューから設定ファイルの切り替えを行います。NYamy がデフォルトで用意しているサンプル設定は 8 つあり、以下の条件の組み合わせとなります。

    1. キーボードは日本語 109 キーボードか、英語 104 キーボードか。

    2. キートップの表示の通りに使うのか、109 (または 104) キーボードを使っているが、104 (または 109) キーボードと同じ配置で使うのか。

    3. Emacs (UNIX で標準的なエディタの一つ) に似せたバインディングを使うかどうか。

    8 つの設定はすべてサブメニューに表示されるので、使っているキーボードと好みに合わせて選んでください。

    デフォルト設定以外に独自の設定が必要な場合は、[設定フォルダ](#HOME)に `.mayu.rb` ファイルを作りそのファイルに設定を記述します。そしてサブメニューで (ホームディレクトリから) を選びます。詳しくは[チュートリアル](#TUTORIAL)と[カスタマイズ](#CUSTOMIZE)を参照してください。

<span class="menu-item"><a name="menu-s"></a>設定(<u>S</u>)...</span>

:   <span class="menu-item">選択(<u>C</u>) ►</span>の選択肢となる設定ファイルを作成します。

    ![](setting-ja.png)

    右側の矢印ボタンでメニューに表示される順序を変更することができます。

    「追加(<u>A</u>)」又は「編集(<u>E</u>)」ボタンを押すか、行をダブルクリックすると編集ダイアログボックスが表示されます。

    ![](edit-setting-ja.png)

    「名前(<u>N</u>)」には、メニューに表示される名前を記述します。「ファイル名(<u>F</u>)」を空欄にすると[設定フォルダ](#HOME)から既定の設定ファイル (`.mayu.rb`) を読み込みます。絶対パスを書いた場合はそのファイルが、相対パスを書いた場合は設定フォルダから検索したファイルが読み込まれます。「シンボル(<u>S</u>)」には、[条件分岐](#cond)で使用されるシンボルを記述します。シンボルの頭に `-D` をつけ、複数のシンボルは `;` で区切ります。

<span class="menu-item">一時停止(<u>T</u>)</span>

:   NYamy の機能を一時的に停止します。キーボードからの入力は、NYamy が存在しない時と同じ動作をします。このとき、タスクトレイのアイコンは ![](pause-ja.png) になります。

<span class="menu-item">**<a name="menu-i"></a>調査(<u>I</u>)...**</span>

:   調査ウインドウとログウインドウを表示します。

    ![](investigate-ja.png)

    それぞれの場所でキーを押すことにより、キーのスキャンコードや仮想キーコードを調べることができます。

    また、![ターゲット](target.png) を調べたいウィンドウまでドラッグするとウィンドウクラスとウィンドウタイトルがログに出力されます。ここで調査したウィンドウクラス名とウィンドウタイトルは、設定ファイルで [`window`](#keymap) に記述することができます。(ここで調査する代わりに、`⟨FUNCTION⟩` [`&WindowIdentify`](#function_WindowIdentify) を利用しても調べることができます)

    <a name="investigate-elevated"></a>**管理者権限で動作しているウィンドウは調査できません。** タスク マネージャーやレジストリ エディタのように昇格して動作するアプリケーションが対象の場合、ドラッグしても結果がログに出力されません。Windows は、権限の低いプロセスが権限の高いプロセスのウィンドウへメッセージを送ることを禁じているためです (UIPI)。NYamy 自身を管理者権限で起動すれば調査できますが、常用は勧めません。

    同じ理由で、**昇格したウィンドウが「常に手前に表示」になっている場合はハイライトの枠も表示されません**。枠はウィンドウの縁の上に描かれるため、対象がひとつでも手前にあると完全に隠れます。

<span class="menu-item"><a name="menu-l"></a>ログ(<u>L</u>)...</span>

:   ログウインドウを表示します。

    ![](log-ja.png)

    [調査(<u>I</u>)...](#menu-i)の結果やエラーなどがここに表示されます。(「□詳細(<u>D</u>)」をチェックすると、NYamy の内部の変換処理が詳細に表示されますが非常に難解です)

<span class="menu-item"><a name="menu-k"></a>チェック(<u>K</u>)...</span>

:   現在のキーボードの状態をログウインドウに出力します。押されたままになっているキーと、ロック状態のキー ([[CapsLock]], [[NumLock]], [[ScrollLock]], カナ, 漢字) が表示されます。キーが押しっぱなしとして認識されてしまった場合の調査に利用できます。

<span class="menu-item">バージョン(<u>V</u>)...</span>

:   バージョン情報などを表示します。バグレポートをする時にこの内容をコピーすると便利です。

    ![](version-ja.png)

<span class="menu-item">ヘルプ(<u>H</u>)...</span>

:   このマニュアルを表示します。

<span class="menu-item"><a name="menu-x"></a>終了(<u>X</u>)</span>

:   NYamy を終了します。
