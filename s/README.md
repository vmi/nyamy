# NYamy - New Yamy

本ソフトウェアは「[窓使いの憂鬱](https://sourceforge.net/projects/mayu/)」およびその派生ソフトウェア「YAMY」をベースに大幅な修正を加えたものです。

詳細は `doc\README-ja.html` を参照してください。(NYamyのヘルプ機能でも表示できます)

## インストール

配布 zip を展開し、同梱の `install.cmd` を実行してインストールします。ドライバ等は未使用なので、再起動は不要です。

再インストール時はあらかじめ起動中のNYamyを終了させてください。

## アンインストール

インストール先フォルダ (`%LOCALAPPDATA%\Programs\NYamy`) にある `uninstall.cmd` を実行してください。
